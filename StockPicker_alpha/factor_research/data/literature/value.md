# Value / Book-to-Market (Fama & French)

**Doc id:** `value.md`

Fama, E. F., & French, K. R. (1992). The Cross-Section of Expected Stock Returns.
*Journal of Finance*.

- Book-to-market (BtM / HML-style value) is a classic cross-sectional return predictor.
- Value premia are **cyclical** and can disappear for long stretches; economic link must be checked in-sample.
- Pair with quality/profitability when researching composites to understand factor overlap.
